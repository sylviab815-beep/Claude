# Names Avoidance Reference

If the user provides a Names Avoidance List (a list of character names previously used in their catalog or names they wish not to use), cross-reference all character names from the outline against the list before drafting begins.

## Process

1. **Phase 3 Pre-Writing Setup** — request the Names Avoidance List from the user (file upload, paste, or list of names).
2. **Cross-reference** — check every character name from the outline against the list.
3. **Replace** — for any matches, generate replacement names appropriate to:
   - The character's era (classic pulp, mid-century, contemporary, retro-futurist)
   - The character's cultural background
   - The character's role
4. **Document** — record original name → replacement name in the ARIS chapter log so the user has a record.
5. **Update outline** — adjust the outline document with the replacements before drafting.

## If No List Provided

If the user has no Names Avoidance List, proceed with names from the outline as-is. Do not generate substitutions unnecessarily.

## Cultural Sensitivity in Names

When generating names — whether for replacements or for new characters — observe:

- Names should match the character's actual cultural background, not exoticized stand-ins
- Surnames should follow the naming conventions of that culture
- Era-specific given names should be appropriate to the character's birth year
- Avoid overused "fantasy-flavored" names for real-world cultures
- For non-English cultures, verify spelling and diacritics

## Common Adjustments

| Era | Avoid | Reach For |
|-----|-------|-----------|
| Classic Pulp | Stock British "explorer" names without backing | Specific regional naming consistent with the character's documented background |
| Contemporary | Generic Anglophone names for international characters | Authentic cultural naming with first/family-name conventions of the character's culture |
| Retro-Futurist | Sci-fi-typical neologistic names | Names that match the alternate-history's logic |

## Recording

In the ARIS chapter log, the names section records:

```
Names Cross-Check
- [Original]: [Replacement] — Reason
- [Original]: [Replacement] — Reason
[OR]
- No avoidance list provided; no substitutions made
```
